# Feliz mes, amor

Landing romántica con recuerdos en línea de tiempo. Hecha con Vite, React y Tailwind.

## En la compu

```bash
npm install
npm run dev
```

Abre `http://localhost:5173`. Con `npm run dev` también queda visible en la red local para probarlo en el celular.

## Subir a Vercel

1. Subí el repo a GitHub.
2. En [vercel.com](https://vercel.com) importá el proyecto.
3. Framework: Vite. Build: `npm run build`. Salida: `dist`.
4. Deploy. Te va a dar una URL pública para mandarle.
